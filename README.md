# scoop-bucket

Patrick Hayes' Scoop bucket for command-line tools (Windows).

## Usage

```
scoop bucket add phayes https://github.com/phayes/scoop-bucket
scoop install <app>
```

## Manifests

Manifests in `bucket/` are generated and pushed automatically by each source
project's release workflow (see `scripts/gen-scoop-manifest.sh` in the
project repos) right after a GitHub Release is published. Don't edit them
by hand — a manual edit will be overwritten on the project's next release.
